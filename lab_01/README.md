# Лабораторная работа 1. Консольный набор утилит

Программа `toolkit` для командной строки. Умеет две вещи:

- считать выражения (калькулятор);
- переводить величины из одних единиц в другие (конвертер).

## Установка

Нужен Python 3.11 или новее. Команды запускать из папки `lab_01`:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

## Команды

```bash
python -m toolkit calc "EXPRESSION"
python -m toolkit convert VALUE --from UNIT --to UNIT
python -m toolkit --help
```

## Калькулятор

```console
$ python -m toolkit calc "2+3*4"
14
$ python -m toolkit calc "10 / 4"
2.5
$ python -m toolkit calc "-2 * -3"
6
$ python -m toolkit calc "(12-25)*3-21*2"
-81
$ python -m toolkit calc "7 // 2"
3
$ python -m toolkit calc "7 % 2"
1
```

Выражение нужно писать в кавычках.

Что умеет:

- целые и дробные числа: `2`, `1.5`;
- сложение `+`, вычитание `-`, умножение `*`, деление `/`;
- деление нацело `//` и остаток `%`;
- корректно обрабатывает знак перед числом и перед скобкой: `-2`, `+3`, `-(1+2)`;
- корректно обрабатывает скобки;
- пробелы можно ставить где угодно между числами и знаками.

### Деление нацело и остаток с отрицательными числами

Работают так же, как в Python:

- `//` округляет результат вниз: `7 // 2` даёт `3`, а `-7 // 2` и `7 // -2` дают `-4`;
- у остатка `%` знак такой же, как у делителя: `7 % 2` и `-7 % 2` дают `1`, а `7 % -2` даёт `-1`.

## Конвертер

```console
$ python -m toolkit convert 1000 --from mm --to m
1
$ python -m toolkit convert 1.5 --from kg --to g
1500
$ python -m toolkit convert 100 --from c --to f
212
$ python -m toolkit convert 2.5 --from KM --to m
2500
```

Единицы:

- длина: `mm`, `cm`, `m`, `km`;
- масса: `g`, `kg`;
- температура: `c`, `f`, `k`.

Правила:

- большие и маленькие буквы не различаются: `KM` и `km` — одно и то же;
- переводить можно только внутри одной группы: `kg` в `m` перевести нельзя;
- температура не может быть ниже абсолютного нуля (0 K).

## Ошибки

Если ввод неправильный, программа пишет, что не так, и завершается с кодом `2`.
Если всё хорошо, она печатает результат и завершается с кодом `0`.



Какие ошибки программа находит:

- пустое выражение;
- недопустимый символ: `2+a`;
- пропущено число: `2+`;
- два знака подряд: `2*/3`;
- непарные скобки: `(1+2`;
- деление на ноль: `1/0`, `7//0`, `7%0`;
- неверное число: `1..2`, `abc`;
- неизвестная единица: `tugrik`;
- единицы из разных групп: `kg` и `m`;
- температура ниже абсолютного нуля.

Результат печатается в stdout, ошибки — в stderr.

## Как устроен калькулятор

Выражение считается в четыре шага. Каждый шаг — отдельная функция в `calculator.py`.

1. `tokenize` — делит строку на части: числа, знаки и скобки.
2. `validate` — проверяет, что выражение записано правильно.
3. `trans_polish` — переставляет части в польскую запись, чтобы учесть порядок действий.
4. `calc_polish` — считает результат с помощью стека.

Функция `calculate` вызывает их по очереди.

### Как разбирается `-2*-3`

Знак `-` или `+` относится к числу (а не означает вычитание или сложение), если перед ним
нет числа. Так бывает в начале выражения, после другого знака или после `(`.

- Первый `-` стоит в начале. Значит, это знак числа: получается `-2`.
- `*` стоит после числа. Это умножение.
- Второй `-` стоит после `*`. Значит, это знак числа: получается `-3`.

В итоге `-2` умножается на `-3`, ответ `6`.

## Как устроен конвертер

Функция `convert` в `converter.py`.

- Для длины и массы есть таблицы: сколько миллиметров или граммов в каждой единице.
  Значение сначала переводится в миллиметры или граммы, потом в нужную единицу.
- Температура сначала переводится в кельвины, потом в нужную единицу.

## Особенности

- `1+-2` считается правильным выражением, ответ `-1`.
- Знак можно ставить перед числом и перед скобкой: `-(1+2)` даёт `-3`, `--2` даёт `2`.
- Несколько знаков подряд допустимы: первый после числа - действие, остальные относятся
  к числу. `1 --- 2` — это `1 - (-(-2))`, ответ `-1`.
- Ошибка «два знака подряд» возникает, только когда второй знак не может относиться к числу:
  `2*/3`, `1 -* 2`.
- Целые ответы печатаются без `.0`: `14`, а не `14.0`.
