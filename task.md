# Лабораторная работа 1. Консольный набор утилит

## Результат

Python-пакет с CLI, содержащий калькулятор и конвертер величин.

## Обязательные команды

```text
python -m toolkit calc "EXPRESSION"
python -m toolkit convert VALUE --from UNIT --to UNIT
python -m toolkit --help
```

## Калькулятор

- Поддержать целые и вещественные числа.
- Поддержать `+`, `-`, `*`, `/`.
- Поддержать унарный `+` и `-` перед числом.
- Игнорировать пробелы между токенами.
- Соблюдать приоритет `*` и `/` над `+` и `-`.
- Запретить `eval`, `exec`, `ast.literal_eval` и сторонние parser-библиотеки.
- Разделить tokenization, validation и calculation.
- Не использовать `input()` и `print()` внутри вычислительного ядра.

## Конвертер

Поддержать группы:

- длина: `mm`, `cm`, `m`, `km`;
- масса: `g`, `kg`;
- температура: `c`, `f`, `k`.

Правила:

- регистр единиц не учитывается;
- конвертация между разными группами запрещена;
- температура ниже абсолютного нуля запрещена;
- результат возвращается как `float`.

## Ошибки

Обработать:

- пустое выражение;
- недопустимый символ;
- пропущенный операнд;
- два бинарных оператора подряд;
- деление на ноль;
- неизвестную единицу;
- несовместимые единицы;
- неверное числовое значение.

CLI выводит ошибку в stderr и завершается с кодом `2`. Успешная команда завершается с кодом `0`.
